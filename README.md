## 🔊 Voice / Яндекс Станция и Алиса

| Файл | Описание | Установка |
| ---- | -------- | --------- |
| [**script/alice_smart_speaker_parallel.yaml**](https://github.com/BrainDeLook/home-assistant-blueprints/blob/main/script/alice_smart_speaker_parallel.yaml) | **[RU]** Скрипт «Алиса: Умный рупор» для озвучивания уведомлений и выполнения команд на одной или нескольких колонках Яндекс Станции. Умные стратегии громкости с возвратом исходного уровня у каждой колонки, голоса, эффекты (шёпот, мегафон и др.) и большая база звуков. **Отличие от оригинала: запускается в режиме `parallel`, поэтому вызовы для разных колонок с разными текстами выполняются одновременно, а не по очереди.** | [![Import Blueprint](https://my.home-assistant.io/badges/blueprint_import.svg)](https://my.home-assistant.io/redirect/blueprint_import/?blueprint_url=https%3A%2F%2Fraw.githubusercontent.com%2FBrainDeLook%2Fhome-assistant-blueprints%2Fmain%2Fscript%2Falice_smart_speaker_parallel.yaml) |

**Требования:** интеграция [YandexStation](https://github.com/AlexxIT/YandexStation) (`media_player` колонок и `tts.yandex_station_say`).

**Как пользоваться:**

1. Импортируйте блюпринт кнопкой выше.
2. Перейдите в **Настройки → Автоматизации и сцены → Скрипты → Добавить скрипт → Использовать проект** и выберите «Алиса: Умный рупор (параллельный)».
3. Сохраните скрипт.
4. В автоматизации в блоке «Тогда» выберите **Выполнить действие** и найдите свой скрипт. Укажите колонку, текст, громкость, голос и эффект.

**Ограничение параллельного режима:** не вызывайте скрипт одновременно для одной и той же колонки. Запуски могут конфликтовать при установке и возврате громкости. Для разных колонок проблемы нет.

**Если нужна очередь:** используйте оригинальный блюпринт (режим `queued`).

**Благодарности:** основано на блюпринте [Eugen417/homeassistant-blueprints](https://github.com/Eugen417/homeassistant-blueprints/blob/main/script/ya_st_alice_simple.yaml) (v4.7). Единственное функциональное изменение: режим запуска `queued` заменён на `parallel`.

## 🤖 Dreame / Свет вслед за пылесосом

| Файл | Описание | Установка |
| ---- | -------- | --------- |
| [**dreame_room_light.yaml**](dreame_room_light.yaml) | **[RU]** Включает свет после въезда Dreame в комнату, задаёт яркость и RGB-цвет или температуру белого. При выезде восстанавливает состояние каждого светильника до въезда. Отдельные задержки въезда и выезда защищают от скачков координат между соседними комнатами. На базе свет восстанавливается без задержки. | [![Import Blueprint](https://my.home-assistant.io/badges/blueprint_import.svg)](https://my.home-assistant.io/redirect/blueprint_import/?blueprint_url=https%3A%2F%2Fgithub.com%2FBrainDeLook%2Fhome-assistant-blueprints%2Fblob%2Fmain%2Fdreame_room_light.yaml) |

**Требования:** Home Assistant 2024.10+ и интеграция Dreame, предоставляющая у сущности `vacuum` атрибуты `current_segment` (текущая комната), `selected_map_id` (карта) и `docked` (булево нахождение на базе). Отдельный датчик комнаты не нужен. Нахождение на базе определяется по `docked`, включая завершённую зарядку и промежуточные возвращения для мойки.

**Настройка:**

1. Импортируйте блюпринт кнопкой выше и создайте из него автоматизацию.
2. Выберите сущность пылесоса, ID карты и ID комнаты. Посмотреть их можно в **Инструменты разработчика → Состояния**: `selected_map_id`, список комнат `rooms` и текущий `current_segment`.
3. Выберите отдельные сущности `light` этой комнаты, яркость и режим света: RGB, температура белого или только яркость. Все выбранные светильники должны поддерживать выбранный режим и яркость. Для разных настроек разделите светильники на отдельные автоматизации.
4. Установите задержки подтверждения въезда и выезда. По умолчанию обе равны **3 секундам**. Значение **0** отключает соответствующую задержку. Краткий выезд с возвращением до окончания задержки не перезаписывает снимок.
5. Сохраните автоматизацию. Для остальных комнат создайте новые автоматизации из того же блюпринта.

**Как восстанавливается свет:** снимок создаётся непосредственно перед изменением света после подтверждения въезда. При выезде восстанавливаются включённость, яркость и цвет/температура, доступные через интеграцию светильника. После восстановления снимок удаляется; при следующем въезде сохраняется новое актуальное состояние. Во время задержки выезда свет предыдущей комнаты ещё остаётся изменённым — это позволяет игнорировать краткие скачки координат. Свет в разных комнатах может ненадолго пересекаться по времени.

**Ограничения:**

- Выбирайте отдельные светильники, а не группы. Один и тот же светильник не должен участвовать в нескольких экземплярах этого блюпринта.
- Все выбранные светильники должны быть доступны при въезде. Если хотя бы один имеет состояние `unknown`/`unavailable`, свет комнаты не изменяется; повторная попытка произойдёт при следующем подтверждённом въезде.
- Ручные изменения света или команды других автоматизаций во время присутствия робота при выезде заменяются сохранённым состоянием. Блюпринт не блокирует другие автоматизации освещения.
- Снимки `scene.create` временные: **перезапуск Home Assistant или перезагрузка сцен во время работы удалит сохранённое состояние**. Автовосстановление после этого невозможно. Перед перезапуском, отключением, удалением или изменением автоматизации дождитесь выезда робота и восстановления света. Не меняйте её `entity_id`, пока снимок активен.
- При недоступности пылесоса или смене карты свет восстанавливается после задержки выезда. Пауза робота внутри комнаты сохраняет свет до выезда/базы; состояние `cleaning` для работы не требуется, поэтому проезд при возвращении на базу тоже учитывается.
- Сохраняются состояния, которые поддерживает Home Assistant: внутренние динамические палитры и эффекты производителя могут восстанавливаться не полностью. Обесточенную или недоступную лампу восстановить в этот момент нельзя.
- Кнопка «Выполнить действия» не имитирует въезд. Проверяйте автоматизацию реальным изменением комнаты. Задержки `for` начинают отсчёт заново после перезагрузки автоматизаций.

## 🚀 Как установить

Нажмите кнопку **Import Blueprint** напротив нужного файла.

Для ручной установки скопируйте YAML-файл в каталог Home Assistant:

| Тип | Путь |
| --- | ---- |
| Автоматизация (`tv_content_action.yaml`) | `/config/blueprints/automation/personal/tv_content_action.yaml` |
| Автоматизация (`dreame_room_light.yaml`) | `/config/blueprints/automation/personal/dreame_room_light.yaml` |
| Скрипт (`alice_smart_speaker_parallel.yaml`) | `/config/blueprints/script/personal/alice_smart_speaker_parallel.yaml` |

Затем перезагрузите автоматизации/скрипты или Home Assistant.
